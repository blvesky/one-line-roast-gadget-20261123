One roast of an everyday gadget, one line, under 200 characters — written by
`main.py` to `/output/entry.txt` for make.fun's "One-Line Roast: The Gadget
You Use Every Day" bounty ($5 in USDC).

> My smartwatch interrupted a panic attack to congratulate me on hitting my
> daily cardio goal.

## Run it

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt` (override with `MAKEFUN_OUTPUT` for
local testing). Deterministic: the same text on every run. Stdlib only, no
network, no secrets.
